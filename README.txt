ΑΠΑΝΤΗΣΕΙΣ ΣΤΙΣ ΕΡΩΤΗΣΕΙΣ:

ΕΡΩΤΗΣΗ 1:

Τα προγράμματα που έχουν υψηλό αριθμό από ivctx συνήθως εκτελούν περίπλοκους υπολογισμούς που απαιτούν μεγάλη δαπάνη χρόνου από την CPU, με αποτέλεσμα, μέχρι την ολοκλήρωσή τους, η διεργασία να έχει γίνει preempted αρκετές φορές.
Ένα παράδειγμα τέτοιων προγραμμάτων είναι οι επιστημονικές προσομοιώσεις.

ΕΡΩΤΗΣΗ 2:

Ένα πρόγραμμα που έχει υψηλό αριθμό από vctx συνήθως περιμένει για input από τον χρήστη και στο περιεχόμενό του καλούνται πολλά system calls.

ΕΡΩΤΗΣΗ 3:

Processes που έχουν μικρό start time δεν μπορεί να είναι user space programs, καθώς ξεκινούν να τρέχουν κατά τη διαδικασία του boot.
Παραδείγματα τέτοιων διεργασιών είναι τα systemd και kthreadd.
Αντίθετα, διεργασίες που έχουν μεγάλο start time είναι user space programs.
