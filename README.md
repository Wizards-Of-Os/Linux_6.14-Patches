# Linux Kernel 6.14 Patches Repository

## Overview

This repository contains **three Linux kernel patches** developed for **Linux Kernel version 6.14**, created as part of the Operating Systems course assignments.

Each patch is maintained in a separate Git branch to ensure clean version control, independent development, and clear separation between implementations.
